feat: 设置页新增「压缩虚拟磁盘」功能（如实标注实测效果）

对 wslc 会话的 storage.vhdx 执行官方标准压缩流程：
  wsl --shutdown -> 提权 diskpart（select vdisk / attach readonly /
  compact vdisk / detach）

关键认知（全部实测）：
- wslc 会话不在 wsl -l 发行版列表里，wsl --manage --compact 管不到它
- 删除镜像后 vhdx 只增不减：拉 163MB nginx 再删，磁盘 +0.0 MB
- diskpart compact 跑完 exit 0，但 825MB -> 825MB（0 回收）
- 挂载进 WSL 执行 fstrim 报告 trim 1006.8GiB，再 compact 仍 0 回收
  （TRIM 不传导到宿主 VHDX 文件）
- 结论：ext4 删除不清零、compact 只收全零块，wslc 会话磁盘目前
  没有可靠的在线回收手段；功能保留但界面如实标注此局限

辅助修正：
- 会话终止的正确命令是 wslc system session terminate（不存在
  wslc session stop；session 在 system 子命令下）
- diskpart 脚本文件必须 UTF-16 编码（路径含中文用户名，ANSI 会乱码）
