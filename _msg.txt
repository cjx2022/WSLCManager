镜像删除（用户反馈两点）：
- 被容器占用的镜像不再提供删除：删除按钮禁用并说明原因
  （键盘路径兜底同样拦截）；未被占用的才可删
- 未占用镜像的确认文案改为如实描述：在虚拟磁盘内删除镜像层、
  列表同步移除；宿主 vhdx 大小不会自动缩小

备份与清理页（左侧菜单新增）：
- 备份容器：wslc container export -o 导出为 tar，可选目标文件夹。
  ⚠ 实测运行中的容器会报 WSLC_E_CONTAINER_IS_RUNNING —— 工具自动
  处理：先停止，导出完成后恢复原来的运行状态（闭环已实测通过）
- 恢复容器：wslc image import 把 tar 导入为镜像（与 export 配对，
  闭环实测：导出 8.30MB -> 清场 -> 导入 -> 用恢复的镜像重建容器并
  成功运行）。端口/环境变量需在新建容器时重新填写
- 清理-重建会话：终止会话（wslc system session terminate）+ 删除
  storage.vhdx，下次使用自动重建空会话；红色卡片强警告（全部容器
  与镜像丢失、不可恢复，请先备份）
